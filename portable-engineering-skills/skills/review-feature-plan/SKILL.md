# Review a feature plan

Read applicable repository instructions, the feature design, plan, checkpoint, relevant domain docs and targeted code. Trace each in-scope requirement and applicable failure scenario to a phase and verification. Check phase size, prerequisites, actual PR bases and stack dependencies, schema/API ordering, domain-doc synchronization, rollout and acceptance. Identify stale assumptions and missing work with evidence, impact and the smallest correction.

If authorized, correct supported plan and checkpoint defects; route material changes in requirements back to the owner instead of silently changing the design. Recheck the full plan after substantive corrections. Report requirement coverage, remaining findings, revised boundaries, decisions and one next action. A plan review alone does not authorize implementation.
