# Complete a feature

Read repository instructions, feature, plan and checkpoint, affected domain docs, relevant code, phase PRs and available CI. Verify scoped acceptance outcomes, merged work, and applicable integration, end-to-end or manual checks. If an acceptance criterion is unmet or evidence is unavailable, record the gap and do not claim unqualified completion. A merged implementation is not evidence of deployment or rollout.

When the repository workflow calls for closeout, consolidate accepted behavior and invariants into the owning domain docs, update verified roadmap status, and create a concise completion record with outcome, decisions, PRs, verification evidence, follow-ups and links to final feature records. Preserve deferred rollout checks and verification limits. Remove or archive working records only as the repository's workflow permits and the user authorizes. Report a reviewable documentation diff and one next action; do not merge without authorization.
